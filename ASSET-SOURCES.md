# Language logo sources

Language logos in `public/languages/` are served locally. They identify the
languages used with Aster and do not indicate endorsement by those projects.

| Asset | Source |
| --- | --- |
| Python | [Python logo resources](https://www.python.org/community/logos/), using the linked logo-only SVG |
| TypeScript | [TypeScript branding](https://www.typescriptlang.org/branding/), using the site's 512px icon |
| Go | [Go logo resources](https://go.dev/blog/go-brand/Go-Logo/SVG/), blue logo |
| Java | [dev.java](https://dev.java/), the site's Java logo |
| .NET | [Official .NET brand repository](https://github.com/dotnet/brand/blob/c7d0f51b8ec59531332d05fb27a5b758a7a3d689/logo/dotnet-logo.svg) |
| Rust | Simple Icons 16.15.0, sourced from [Rust](https://www.rust-lang.org); light fill for the dark background |
| Kotlin | Simple Icons 16.15.0, sourced from [JetBrains brand resources](https://www.jetbrains.com/company/brand/logos/); Kotlin purple fill |

The Simple Icons glyphs were copied from the existing documentation project's
installed package. The website does not require that package at build time.
